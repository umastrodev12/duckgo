# 🦆 Duck Go

DuckGo é uma assistente de IA de programação(similar ao Claude Code) direto no terminal.

## 💻 Instalando o DuckGo

Para instalar o DuckGo, você precisa clonar o repositório, para clonar siga os passos abaixo <3

> [!NOTE]
Você precisa ter o [Bun](https://bun.com) instalado na sua máquina.

1. Rode o comando git
```bash
mkdir duckgo
git clone https://github.com/umastrodev12/duckgo.git
```

## Começando
Você pode iniciar um projeto simples com o DuckGo, exemplo: `Crie um aplicativo com FastAPI de To-Do.`
